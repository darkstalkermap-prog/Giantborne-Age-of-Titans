## Decisions and deviations

1. **Doc name** `docs/systems/P18.md` (the task and §1.1 item 5).
2. **The draw-call follow-up is deferred, not fixed.** FOLLOWUPS gave "views with five or more
   enemy rigs pass 250 draw calls" to "P18 or later", to be fixed only if small and safe. It is
   neither: a visual LOD for rigs changes three actor files (`enemy_actor.gd`, `actor_rig.gd`,
   `quadruped_rig.gd`), needs a range per archetype (the 8.5 m Ogre King must not become a box
   across its own 80 m arena), can only be judged rendered, and would not bring the dense fights
   under 250 anyway (the courtyard's eight enemies are all within 45 m). It is a known limitation in
   the README, the handoff and `docs/PERFORMANCE.md`, and a next-milestone item.
3. **A Valley screenshot tour as a tool script**, not a new Autopilot scenario. Plan §3.21 expected
   P17b to extend `--scenario=capture` to the Valley (optional; not built). `tools/valley_tour.gd`
   runs beside the existing bot and listens to `Events`, so no game or bot file changed for it. It
   names no class whose script uses an autoload (it is loaded before the autoloads exist) and finds
   the Autopilot and the bot by script path.
4. **Two small fixes outside the owned paths**: `ui/hud.gd` (the Destroyed message, with its
   regression suite) and one line of `docs/USABILITY_SCRIPT.md` (the Windows save folder). Nothing
   else in the game changed.
5. **The web check is Chromium with a software GPU** (Playwright, SwiftShader), headless for the boot,
   New Game, the save across a reload and Continue, and headed under Xvfb for the mouse capture.
   Real desktop browsers, real GPUs and the play link inside its hosting frame are NOT RUN.
6. **The pull request text has no attribution line**: the task forbids model names in it; the
   orchestrator, which opens the pull request, adds whatever its own rules ask for.
7. **No balance matrix was re-run.** The game's code and data are those of P17b's final batch except
   the HUD message, which no bot reads; P17b's `final` matrix and 30-minute run stand as the M4/M5
   evidence, and this package adds one assisted novice run on its final code (handoff §6).

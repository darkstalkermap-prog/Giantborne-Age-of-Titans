# P04 — Scene kit, wolf archetype, morale and size tactics, actor masks

Wave 1, lane B (beside P03). Branch `pkg/P04`. Plan: `docs/plans/M2_M5_PLAN.md` §3.4, with the
contracts in §2.2 (layers), §2.4 (`telegraph_started`, `morale_changed`, `enemy_routed`), §2.7.3
(EnemyActor / EnemyBrain), §2.8.2 (the P04 fields), §2.12 (scenes and builders), §4.4 (wolf and
soldier numbers), and decisions 21, 25 and 26.

## What was built

- **Scene kit and builders.** `tools/build_scenes.gd` is now a runner over the pre-declared
  `BUILDERS` list (every planned builder, in dependency order; a missing file is skipped with a
  note). Each builder in `tools/builders/` (`player`, `soldier`, `wolf`, `props`, `sandbox`,
  `main`) exposes `static func build_all(kit: SceneKit)`. `-- --only=<name>[,<name>]` rebuilds
  selected builders. `SceneKit` (`tools/scene_kit.gd`) holds the palette, the node helpers, the
  layer constants, `ACTOR_MASK` and `save()`. `save()` strips the random node `unique_id=`
  attributes and renumbers the resource ids, so regenerating gives byte-identical files.
- **Actor masks.** The giant, soldier and wolf bodies collide with `SceneKit.ACTOR_MASK`
  (51 = world, actors, breakables and blockers, decision 21). Camera sweeps, attack occluders,
  enemy sight and hurtboxes ignore the blockers layer.
- **The wolf** (`enemy.wolf`, the second enemy role): data, `WolfEnemy`, `WolfBrain`,
  `QuadrupedRig`, `scenes/enemies/wolf.tscn`, three materials, and a pack of three
  (`sandbox.wolf_1..3`) on a patrol in the sandbox's north-west corner.
- **EnemyActor** (below `## @anchor P04`, plus small hooks in `_ready`, `_exit_tree`,
  `sim_step`, `_sense`, `_steer`, `_on_any_entity_died`, `on_entity_died`, `_request_token`):
  - scripted `motion` for any action: lunges now, the boss charge (P11a) and the grab lunge (P07)
    later;
  - AI LOD tiers;
  - morale entry points, flight to reachable points, rout;
  - formation slots;
  - the telegraph announcement;
  - enemy sight through `WORLD | BREAKABLE`;
  - the record's nav layers and AI radii;
  - corpses that stop once settled;
  - taking turns with the two attack tokens.
- **EnemyBrain** (below `## @anchor P04`, plus hooks in `_init`, `perceive`, `on_noise`,
  `on_ally_died`, `decide`, `_decide_engaged`, `_attack_finished`, `on_path_failed`):
  - morale: debounce, commander deaths, ×1.5 while outmatched, scripted events, recovery;
  - FLEE / regroup / ROUTED;
  - size tactics: `is_outmatched`, formation HOLD, and hooks for `harass`, `spread`, `kite`
    and `retreat`;
  - attack choice by range band;
  - ATTACK lasts through CASTING (the §2.7.3 fix).
- **SoldierEnemy / SoldierBrain:** the guard stays up in HOLD; documentation only otherwise.
- **Telegraph data.** The soldier chop (0.85 s windup) gets a 2.5 m line and the wolf lunge a
  5 m line. Every shipped enemy attack with a windup of at least 0.8 s now has a telegraph, so
  P01's start-up warning is gone.

### EnemyActor additions (`scripts/actors/enemy_actor.gd`)

```gdscript
const SIGHT_MASK := LAYER_WORLD | LAYER_BREAKABLE     # gates and barricades block sight; blockers do not
const LAYER_BLOCKER := 32
const TIER1_PERCEPTION_INTERVAL := 60; const TIER1_DECISION_INTERVAL := 30; const TIER1_REPATH_TICKS := 60
const FORMATION_GROUP := "ai_formation_points"; const FORMATION_SEARCH_M := 25.0
const FLEE_STEP_DEG := 30.0; const FLEE_MAX_STEPS := 6; const FLEE_PATH_END_M := 1.0
const TOKEN_YIELD_S := 1.0; const TOKEN_WAIT_S := 2.0
var lod_tier := 0; var repath_count := 0
var motion_end_reason := ""      # "", "distance", "wall", "target", "phase"
func _custom_movement(dt) -> bool                 # base now runs the current action's motion
func set_lod_tier(tier: int) -> void               # 0 full; 1 reduced; 2 dormant; callable before ready
func request_repath() -> void                       # drop the agent target as a path failure does
func on_morale_delta(delta: float, source_id: String) -> void
func on_morale_event(event: StringName) -> void     # "siege_destroyed" -20; unknown -> push_warning
func is_routed() -> bool
func capsule_gap(t: CombatEntity) -> float          # horizontal gap between the two capsules
static func entity_radius(t: CombatEntity) -> float # giant: profile capsule; else its record
func nav_region_for_layers() -> RID                 # LevelRoot.nav_region(lowest layer) or the map's region
func formation_marker() -> Node3D                   # the claimed marker, or null
func is_corpse_settled() -> bool
```

- **`motion`** (§2.8.2). The motion runs during `motion.phase`:
  - The direction is the facing when that phase begins. It turns toward the brain's target at
    `steer_deg_s`.
  - Speed is `speed_mps × combatant.move_mult()`, and the total is capped at `max_distance_m`.
  - With `stop_on_wall`, a slide collision against a WORLD body facing the motion ends it. Then
    `controller.force_action(on_wall_action)` runs when one is set (the boss's wall recovery).
  - `approach_stop_m` ends it when the capsule gap to the target is that small.
  - After the end, the actor stands still for the rest of the phase.
  - An archetype that overrides `_custom_movement` should call `super()` first.
- **LOD.**
  - Tier 1: perception every 60 ticks and decisions every 30. The agent gets a new target only
    when it has none: at the start, after a path failure or after `request_repath()`. That
    happens at most once per 60 ticks.
  - Tier 2: `process_mode = DISABLED`, so `Sim` skips the actor. The body and its hurtboxes
    leave physics (`CollisionObject3D.disable_mode` REMOVE): a dormant enemy can neither be hit
    nor block. Its attack tokens are released. `Visual/Body` is hidden and `Visual/LodProxy` is
    shown.
  - Back to tier 0 restores everything.
- **Telegraphs.** `Events.telegraph_started` is emitted on `controller.phase_entered(WINDUP)` for an
  action with `telegraph`. It carries the brain's `target_id`, the actor's position and facing,
  and the windup duration. `radius` and `length` depend on the shape:
  - line: `width_m / 2` and `length_m`;
  - circle: `radius_m` and 0;
  - cone: `radius_m` and `radius_m` (`arc_deg` stays in the action record).
- **Morale inputs.**
  - A same-team death within `ai.ally_death_radius_m` (15) calls `brain.on_ally_died(tick)`.
  - A dying `commander` costs −25 through `brain.on_commander_died(tick)`. Its allies within
    that radius and every member of its encounter pay it.
  - `CombatEntity`'s `morale_damage` (Thunder Roar) arrives through `on_morale_delta`.
  - The brain's signals become `Events.morale_changed(tick, id, morale, delta, reason)` and
    `Events.enemy_routed(tick, id, encounter_id)`.
- **Leader.** Every perception snapshot carries `has_leader`:
  - a living commander is its own leader;
  - when the encounter has (or had) a commander, only a living commander of that encounter
    counts;
  - otherwise, any living ally within `ai.leader_radius_m` (20) that is neither fleeing nor
    routed.
  - Placed actors outside an encounter share the encounter `""`.
- **Flee points.** The brain asks for a point `flee_distance_m` away:
  - Directions are tried in 30° steps from straight away, up to ±180°.
  - Each desired point snaps with `NavigationServer3D.region_get_closest_point` on
    `nav_region_for_layers()`. It is accepted when `map_get_path(map, from, p, true,
    nav_layers)` ends within 1 m of it.
  - When the snapped point lies beyond a wall (on the outside strip of the sandbox, for
    example), the end of that path becomes the candidate and is checked the same way.
  - A candidate must be at least half the distance away and farther from the threat than the
    actor.
  - Without a navmesh, the point is checked with a ray against `SIGHT_MASK | LAYER_BLOCKER`.
  - `Vector3.INF` means cornered, and the brain then stands.
- **Formation slots** (`brain.formation_resolver`):
  - First choice: the nearest free node in group `ai_formation_points` within 25 m whose
    `faction` is `""` or the actor's. The actor claims it with node meta `formation_holder`
    and gives it back on leaving HOLD, death and exit.
  - Otherwise, a place in an ad-hoc line `tactics.formation_spacing_m` (3) apart, through the
    encounter's centre and at right angles to the direction to the giant. The centre is the
    encounter record's `center_m`, or the members' mean home position. Outside an encounter the
    line goes through where the unit began to hold.
  - Slots go to members in the order of their home positions along the line, so nobody
    crosses over.
- **Corpses.**
  - A dead actor keeps `move_and_slide` only until it has settled (on the floor, still, its
    brain DEAD). From then on `sim_step` returns early.
  - `ai.corpse_linger_s > 0` frees it after that time. 0, the default, means the actor never
    frees it; the director frees its own.
- **Taking turns.** A unit that gave its token back less than 1 s ago does not take it again
  while another living unit was refused one in the last 2 s. The refusals are kept as meta on
  the target's CombatEntity.

### EnemyBrain additions (`scripts/ai/enemy_brain.gd`)

```gdscript
signal morale_changed(morale: float, delta: float, reason: String)
signal routed                                         # once
const ALLY_DEATH_MORALE := 10.0; const COMMANDER_DEATH_MORALE := 25.0; const OUTMATCHED_LOSS_MULT := 1.5
const MORALE_RECOVERY_PER_S := 2.0; const MORALE_RECOVERY_DELAY_S := 6.0; const MIN_FLEE_S := 4.0
const MORALE_EVENTS := {"siege_destroyed": -20.0}
const UNSCALED_MORALE_SOURCES := ["awe", "siege_destroyed", "script"]
const HOLD_ARRIVE_M := 0.3; const HOLD_LEAVE_M := 0.8; const HOLD_SLOT_REFRESH_S := 0.5
var start_morale; var ignores_morale; var tactics: Dictionary; var own_height_m; var flee_point
var flee_resolver := Callable()        # (from, threat, distance) -> Vector3 (INF = none); the actor sets it
var formation_resolver := Callable()   # (my_position, target_pos) -> Vector3 slot
var formation_release := Callable()    # () -> void
func on_ally_died(tick := -1) -> void              # -10, debounced by ai.morale_debounce_s (2)
func on_commander_died(tick := -1) -> void         # -25
func on_morale_delta(delta, source_id, tick := -1) -> void   # losses x1.5 while outmatched, except unscaled sources
func on_morale_event(event: StringName, tick := -1) -> bool  # false for an unknown event
func apply_morale(delta, reason, tick := -1) -> void          # clamp 0..100, emits morale_changed
func size_ratio() -> float; func is_outmatched() -> bool; func outmatched_behavior() -> String
func has_leader() -> bool; func in_formation() -> bool; func hold_reach() -> float
func attacks_in_range(edge_m: float) -> Array[String]         # by ai_min_range_m..ai_max_range_m
func choose_attack_in_range(edge_m: float) -> String          # weighted (own RNG) among those
# virtual outmatched hooks, true = handled: _decide_harass (WolfBrain), _decide_spread,
# _decide_kite, _decide_retreat (P09); same arguments as _decide_engaged
```

- **Morale.**
  - Ally deaths cost −10. One counts at most once per `ai.morale_debounce_s` (three deaths in
    2 s cost −10).
  - A commander's death costs −25. It is not debounced, and deaths in its debounce window cost
    nothing more.
  - Losses from attackers, ally deaths and commander deaths count ×1.5 while outmatched.
  - `awe`, `siege_destroyed` and `script` are applied as given.
  - Morale recovers 2/s once 6 s have passed without a loss, up to the record's value. It is
    checked in every `decide()`.
  - `ignores_morale` (bosses) blocks every change and every flight.
- **FLEE.**
  - Entered below `ai.flee_morale` while aware.
  - The unit runs to its flee point. It picks a new one after a path failure, or when the
    target comes within 5 m once it has arrived (at most every 2 s).
  - It regroups after at least 4 s, above `ai.regroup_morale`, and only with a leader
    (`ai.regroup_needs_leader`, default true). It returns to APPROACH, or ALERT when not aware.
  - Without a leader for `ai.rout_after_s` (20) it becomes **ROUTED**.
- **ROUTED.**
  - `aware` stays false for good, so the unit never defers a checkpoint. It never regroups and
    attacks nothing.
  - A certain hit (`on_noise(..., true)`) makes it pick a new flee point away from the hit.
  - `routed` fires once.
- A stagger during FLEE or ROUTED resumes that state afterwards.
- **Outmatched.** `target_height / own height ≥ tactics.outmatched_ratio` (0 = never).
  `_decide_engaged` runs the outmatched behaviour first; an unhandled behaviour fights normally
  and leaves any formation.
- **Formation** (`formation`).
  - HOLD at the resolver's slot (refreshed every 0.5 s), facing the target with the soldier's
    guard up.
  - It walks until 0.3 m from the slot and steps out again only once the slot is 0.8 m away.
  - It strikes with a token only when the target is within `hold_reach()`. That is
    `ai_max_range_m` of `tactics.hold_attack`, or `ai.attack_range_m`, plus the target's
    capsule radius.
  - It strikes with `tactics.hold_attack` when that is set (P11b's brace), otherwise its normal
    pick. Then RECOVER, then back to HOLD.

- `WolfBrain extends EnemyBrain`:
  - Constants: `FLANKED_DEG` 60, `FLANK_PATIENCE_S` 3, `ORBIT_STEP_DEG` 50, `HARASS_REAR_DEG`
    100, `HARASS_FLANK_DEG` 150, `HARASS_RETREAT_M` 8.
  - Members: `flank_sign`, `retreating`, `static angle_from_facing(target_forward,
    from_target) -> float`, `flank_angle(my, target)`, `stand_off_m()` (the middle of the
    lunge band from the giant's centre).
  - It orbits in steps of at most 50° toward ±`tactics.flank_angle_deg` (100) from the giant's
    `target_forward`.
  - Once more than 60° round, or after 3 s without getting there, it attacks with a token: the
    lunge from its band, the bite up close.
  - After an attack it gives the token back and circles for 1.2 s.
  - Outmatched (`harass`, a stage-2 giant: 6.1 ≥ 6.0), it attacks only from more than 100°
    behind and backs off 8 m (at most 3 s) after every attack.
  - `_choose_attack()` picks by range.
- `QuadrupedRig` (`scripts/presentation/quadruped_rig.gd`):
  - a trot with diagonal leg pairs;
  - the head raised in a windup and snapped down on the bite;
  - a low stretch while lunging;
  - a wobble when staggered and a roll onto its side when dead;
  - a swaying tail and hit flashes.
  - It reads `get_rig_state()` only.

## Decisions and deviations

1. **System doc name.** §3.4 lists `docs/systems/P04-enemy-ai-wolf.md`; the package task and the
   earlier packages use `docs/systems/P04.md`.
2. **Wolf lunge active phase 0.45 s (plan table: 0.25 s).** At 9 m/s, 0.25 s dashes only 2.25 m.
   That cannot reach the giant from the planned 2.5–5.5 m lunge band. 0.45 s gives 4.05 m and the
   jaws reach about 1.2 m more, inside the 5 m cap. Windup 0.60 s, recovery 0.90 s and the 5 m cap
   are as planned. The band is authored from the target's capsule surface: 1.65–4.65 m, which is
   2.5–5.5 m from a stage-1 giant's centre.
3. **`SceneKit.save` also renumbers ext/sub resource ids.** Godot draws them from a random stream
   that advances with every save in the process. An `--only` build and a full build would
   otherwise write different files.
4. **Flee points** add the path-end fallback described above. The navmesh's closest-point query
   snaps points beyond a wall onto unconnected strips. Without the fallback, a soldier backed
   into a corner found no destination.
5. **Taking turns with tokens** (not in §3.4). With only the M1 rule, the first two token holders
   take their tokens straight back after every pause, and a third attacker never gets a turn.
   Spec §10 (at most two attackers, the others reposition) is unchanged.
6. **Formation hysteresis** (0.3 m to arrive, 0.8 m to leave), so a line is tidy without shuffling.
7. **Harassing wolves back off after every attack** (bite or lunge), not only after lunges.
8. **A commander's death** costs −25 to allies within `ally_death_radius_m` and to every member of
   its encounter, wherever they are. It is ×1.5 while outmatched, like the other ally losses.
9. **Tier 1 movement.** With a goal that moves and no path failure, the agent keeps its old target
   (§3.4: "re-paths only after a path failure"). At the end of that path the actor steers
   directly, and a stall becomes the path failure that re-paths.
10. **Defaults in code.** The new `ai` keys are optional and use the plan's defaults. The shipped
    records do not repeat them.
11. **`on_ally_died(tick := -1)`.** The M1 call without arguments still works and uses the brain's
    last tick.
12. **The sandbox navmesh** keeps its geometry mask: the sandbox has no blockers. P10b's offline
    Valley bake must treat layer 6 as an obstacle (decision 21).
13. **A dormant actor (tier 2) releases its attack tokens.** Otherwise an enemy left behind
    mid-attack would keep one of the giant's two slots while it sleeps. The DISABLED process mode
    also takes its body and hurtboxes out of physics until it wakes; the plan does not say this,
    and P10a should know it.
14. **Existing tests changed:**
    - `test_obstacle_route` and `test_ai_and_world_fixes` disable every AI with
      `TestSpawn.disable_all_ai` (planned).
    - P01's `test_schemas_v2.test_untelegraphed_enemy_attack_warns` copies the shipped chop to
      build an untelegraphed attack, so it now strips the telegraph P04 added from its copy.

### The seeded soak stopped breaking the fence

- **Finding.** After the wave merge, `--autoplay=120` broke no fence (`fence_breaks` 0,
  `max_debris` 0; before P04 they were 2 and 8). The soak picked the first living enemy, so once
  the soldier died it crossed the arena to the wolf pack. It turned to the fence only when no
  enemy was left, and the 12 s respawn came first. The definition-of-done soak had stopped
  covering the breakable, the debris pool and loot.
- **Fix.** `Autopilot.pick_soak_target` (a static function) sets the order:
  1. the nearest living enemy within `ENGAGE_RADIUS_M` (10 m) of the giant, or within
     `ARENA_RADIUS_M` (40 m) of the arena centre (the soldier's patrol);
  2. an intact breakable;
  3. the nearest other living enemy (the wolves);
  4. a dummy.

  The result line gains `loot_awards`. When the soak runs for 120 s or more, `tools/check.sh`
  now fails unless `fence_breaks`, `max_debris` and `loot_awards` are all at least 1. A later
  content change therefore cannot drop this coverage silently. P14 and P17a, the next editors of
  `autopilot.gd`, should keep this order, or an equivalent one, and the `loot_awards` count.
- **Result.** `--autoplay=120`: `fence_breaks` 1, `max_debris` 8, `loot_awards` 1, `enemy_kills`
  5 (2 soldiers, 3 wolves), `resets` 1, 0 errors. `--autoplay=300`: `fence_breaks` 4,
  `max_debris` 8, `loot_awards` 4, `enemy_kills` 13, `resets` 3, 0 errors. With the old target
  rule, `tools/check.sh` now stops with "the soak no longer covers the breakable path
  (fence_breaks: 0)".
- **Tests.** `tests/integration/test_autopilot_soak.gd` (25 checks, about 0.25 s) checks the
  order with stand-in nodes. It also checks the real sandbox layout: the wolves and their patrol
  lie outside 40 m, and the soldier's patrol inside. From the player spawn the soak goes to the
  soldier, then the fence, then the wolves.

# A5 — Milestone A's gate: what was broken, what was fixed, what is left

A5 reviewed milestone A (A1-A4, merged since `0.13.0-m13`: Stoneback, his quarry and quest, the topple, the Character
menu, save schema 3 and the intro cutscene) independently of the packages' own claims, on `pkg/a5` from the dev head
(`9460595`). Every suspicion was run before it was called a finding: the real game under Xvfb driven by the UI probe,
the Web release in headless Chromium, the real open world in the gate tier, and saves the released `0.13.0-m13` build
wrote. Confirmed findings were fixed, each with a test that fails before its fix; what is a design choice or large is in
`docs/plans/FOLLOWUPS.md`, "From the milestone A gate (A5)". The decisions are in `docs/DECISIONS.md` §3.8.

## The UI probe's intro tour (`scripts/debug/ui_probe.gd`)

    xvfb-run -a -s "-screen 0 1280x720x24" tools/gd.sh --path . --rendering-driver opengl3 --resolution 1280x720 -- \
      --no-user-settings --mode=world --ui-probe=intro --ui-probe-skip=<open|TICK|end> \
      --ui-probe-skip-key=<enter|esc|space|pad_a|pad_b|pad_start>

prints one `UI_PROBE {"t":"intro", ...}` line (paused, gameplay_context, hud_shown, top, camera_is_players,
player_shown, player_above_ground_m, cutscene_nodes, stoneback_rigs, titans, music, seen, played, walked_m, ok) and
quits with 0 when the play after the intro is right.

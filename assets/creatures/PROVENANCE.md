# Provenance of `assets/creatures/`

Every file here is generated by `tools/giant/build_people.py --horse` (P61, plan M11 §2.8, §3.14) and listed with its
sha256 in `manifest.json`; `build_people.py --verify` regenerates them bit-exact.

| File | Derived from |
| --- | --- |
| `horse.glb` (the bare and the tacked horse on 25 bones) | wholly the project's code: `tools/giant/kit/quadruped.py` (a signed distance field of the project's own anatomical parts, polygonized, smoothed, decimated, unwrapped and weighted by the script). No outside mesh, scan or texture; none of the CC0 MakeHuman data is read |
| `horse_poses.glb` (the gait's extremes) | wholly the project's code (`quadruped.POSES`) |
| `horse_albedo.png`, `horse_normal.png`, `horse_orm.png` | wholly the project's code: the coat, the strands, the leather, the metal and the housing are procedural (`quadruped.coat`, `hair_tile`, the value noise of `people_bake.py`); the normal map is the dense field's normals; the ambient occlusion is ray cast against the horse itself |

The horse's pipeline borrows the people pipeline's own modules (`people_outfit.py`: decimation, unwrap, tangents,
export; `people_bake.py`: the rasterizer and the noise; `people_roles.py`: the palette bands), which are the project's code.

# Provenance of `assets/creatures/`

Every file here is generated by `tools/giant/build_people.py --horse --brutes --wolves --stoneback` (P61 and P63, plan M11 §2.8,
§3.14, §3.16; A1) and listed with its sha256 in `manifest.json`; `build_people.py --verify` regenerates them bit-exact.

| File | Derived from |
| --- | --- |
| `horse.glb` (the bare and the tacked horse on 25 bones) | wholly the project's code: `tools/giant/kit/quadruped.py` (a signed distance field of the project's own anatomical parts, polygonized, smoothed, decimated, unwrapped and weighted by the script). No outside mesh, scan or texture; none of the CC0 MakeHuman data is read |
| `horse_poses.glb` (the gait's extremes) | wholly the project's code (`quadruped.POSES`) |
| `horse_albedo.png`, `horse_normal.png`, `horse_orm.png` | wholly the project's code: the coat, the strands, the eyes, the leather, the metal and the housing are procedural (`quadruped.coat`, `coat_flow`, `hair_tile`, the value noise of `people_bake.py`); the normal map is the dense field's normals and the coat's streaks; the ambient occlusion is ray cast against the horse itself |
| `wolf.glb` (the wolf, its fur shell's mesh and its far mesh on 25 bones), `wolf_poses.glb` | wholly the project's code: `quadruped.py`'s wolf (`WOLF`, `wolf_sdf`, `fur_cards`, `WOLF_POSES`); none of the CC0 MakeHuman data is read |
| `wolf_albedo.png`, `wolf_normal.png`, `wolf_orm.png`, `wolf_fur.png` | wholly the project's code (`wolf_coat`, `wolf_flow`, `wolf_fur_length`, `hair_tile`, the noise of `people_bake.py`) |
| `ogre.glb`, `troll.glb` (the brutes on the people's 23 bones: the whelp, the bosses' gear, the far meshes) | **derived from the CC0 MakeHuman data** (`tools/giant/mpfb2/`: the same audited files the giant and the people read - the hm08 base mesh, the macro and detail targets, the game_engine rig and its weights; no file was added), reshaped by the project's code (`tools/giant/kit/brute.py`: `giant_body.proportioned` with the brutes' tables, then `brute.reshape`) and dressed in the giant's garment shells (`giant_garment.py`); the tusks and the crowns are the project's own shapes |
| `ogre_clips.glb`, `troll_clips.glb` | the project's code (`clips.py`'s generator and `brute.py`'s clips) on the brutes' CC0-derived skeletons |
| `ogre_albedo.png`, `ogre_normal.png`, `ogre_orm.png`, `troll_albedo.png`, `troll_normal.png`, `troll_orm.png` | the project's code (`people_bake.py`'s bake of the derived meshes, repainted by `brute.repaint`: the hides, the moss, the warts) |
| `stoneback.glb` (A1: Stoneback, the quarry titan, on the people's 23 bones: the body and hide kilt, eight stone plates, the shackles, the trunk-club, the boulder, the far mesh) | the body **derived from the CC0 MakeHuman data** (`tools/giant/mpfb2/`, the same audited files; none added), reshaped by `brute.py`'s code with `tools/giant/kit/stoneback.py`'s tables and dressed in the giant's garment shells; the plates (the body's own surface made into chiselled slabs), the cuffs and chains, the trunk, its root ball and the boulder are the project's own shapes (`stoneback.py`) |
| `stoneback_clips.glb` | the project's code (`clips.py`'s generator, `brute.py`'s gaits and idle, `stoneback.py`'s held arms and wind-ups) on his CC0-derived skeleton |
| `stoneback_albedo.png`, `stoneback_normal.png`, `stoneback_orm.png` | the project's code (`people_bake.py`'s bake, repainted by `stoneback.repaint`: the hide, the quarry dust, the pale scarred skin under the plates, the kilt's hide, the iron tile) |
| `stoneback_stone_albedo.png`, `stoneback_stone_normal.png`, `stoneback_bark_albedo.png`, `stoneback_bark_normal.png` | wholly the project's code (`stoneback.detail_textures`: tileable value noise of `people_bake.py`); no photograph or outside texture |

The creatures' pipelines borrow the people pipeline's own modules (`people_outfit.py`: decimation, unwrap, tangents,
export; `people_bake.py`: the rasterizer, the noise and the bake; `people_body.py`: the person and the clips' helpers;
`people_roles.py`: the 23 bones and the palette bands), which are the project's code.

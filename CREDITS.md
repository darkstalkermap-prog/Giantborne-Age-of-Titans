# Credits

Giantborn: Age of Titans is made by its owner and the project's own generators. This file lists every
outside source of data in the game and the tools its assets are built with.

## Data from outside the project

### MakeHuman / MPFB2 body data (CC0 1.0)

- **Used for:** the realistic giant's body, skeleton and skin weights (`assets/giant/`), through the
  vendored subset in `tools/giant/mpfb2/`: the hm08 base mesh, 122 morph targets, the regional
  modifier table, the "game_engine" rig and its weights, and six region mask images.
- **Authors:** the MakeHuman project (makehumancommunity.org) and MPFB2, the MakeHuman plugin for
  Blender. The base mesh's header names the copyright holders at its release to CC0 in September 2020:
  Data Collection AB, Joel Palmius, Jonas Hauquier.
- **Licence:** CC0 1.0 Universal (`tools/giant/mpfb2/LICENSE.md`); the weights file carries
  `"license": "CC0"`.
- **Obtained from:** the data folder of the Python wheel `anny-0.6.2-py3-none-any.whl` (the PyPI package
  `anny` 0.6.2), copied as data only; `tools/giant/mpfb2/SOURCE.md` and `tools/giant/fetch_mpfb2.py` (the
  audit) record how. None of the wheel's code (Apache-2.0) is part of the game or its tools.
- **Details:** `assets/giant/PROVENANCE.md`.

## Made by the project

- **The giant's textures, designs, hair cards, garments and eyes**: generated by `tools/giant/`
  (`assets/giant/PROVENANCE.md`).
- **Every sound and piece of music**: synthesized by `tools/audio/` (`assets/audio/PROVENANCE.md`).
- **The world, the actors' low-poly rigs, the weapons and the props**: generated by the scene builders
  in `tools/builders/` and the world tools in `tools/world/`.

## The engine

- **Godot Engine** 4.6.3 (MIT licence, godotengine.org) - the engine the game runs on; every export
  carries it.

## Tools (used to build the assets, not shipped with the game)

- **Blender** 5.3 as the `bpy` Python module (GPL-3.0-or-later) - builds and bakes the giant; nothing of
  Blender is redistributed.
- **numpy**, **scipy** (BSD-3-Clause), **Pillow** (MIT-CMU), **OpenEXR** (BSD-3-Clause) - the giant and
  audio pipelines.
- **FFmpeg** with **libvorbis** - encodes the music and ambience (`tools/audio/`).
